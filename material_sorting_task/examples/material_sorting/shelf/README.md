# 货架状态、层位几何与放置反馈

`shelf/` 目录负责货架层位的几何映射、语义状态融合、任务一空层放置反馈以及任务二/三对已识别货架物体的复用。它不创建新的 ROS 节点，主要消费感知节点已经发布并由 Client 融合后的世界坐标观测。

## 文件职责

| 文件 | 作用 |
| --- | --- |
| `state_tracker.py` | 融合彩色物体、白色包装箱和空层，形成稳定 `ShelfState`。 |
| `shelf_geometry.py` | 货架中心、层板高度、物体中心和层位分类。 |
| `task3_geometry.py` | 任务三包装箱和左侧放置几何。 |
| `target_center.py` | 目标中心和观察姿态辅助。 |
| `task_memory.py` | 跨任务保存任务一识别出的货架状态和桌面原点。 |
| `placement_feedback.py` | 下降、接触确认、释放和清理阶段的反馈控制。 |
| `manipulation.py` | 滑台保持、回撤和释放动作控制器。 |

## ShelfState 的形成

```text
/material/detections
        |
  ShelfStateTracker
  ROI + 时间新鲜度
  排除手持物
        |
   多帧层位投票
        |
 独立锁定彩色物 / 包装箱
        |
  语义空层补集计算
        |
  任务一严格 RGB-D 空层确认
        |
      ShelfState
```

彩色物和白色包装箱的历史独立维护，避免某个物体暂时被机械臂遮挡时把另一个物体的有效票据淘汰。世界坐标中心使用坐标分量中值，不把物体强行吸附到货架中心。空层没有可检测实体，中心由货架标定几何、层板高度、物体半高和支撑间隙推导。

## 空层安全门

任务一构造 `ShelfStateTracker(require_empty_confirmation=True)`。因此只有以下条件同时满足时才允许放置：

1. 彩色物体和白色包装箱已经在不同层稳定锁定。
2. 语义补集得到唯一候选空层。
3. 感知模块的 RGB-D 后板证据在多帧中确认同一空层。
4. 两种证据的层号一致。

候选空层为 L1 且手持物遮挡时，任务一在货架外降低手持物中心，等待稳定后清空旧空层票并重新采样。主动观察改变的是可见性，不是对空层结论的替代；没有新的 `shelf_empty L1` 证据仍然不能进入放置。

## 放置反馈

放置阶段使用滑台下降、接触候选、接触确认、释放、释放后清理的子阶段。任务一采用更慢的释放速度和更严格的横向容差，任务二、三保留各自的放置几何。放置完成后不立即假设任务成功，而是等待 Server 裁判和本地 `VERIFY_PLACE` 阶段。

## 失败处理

- 同层同时出现彩色物和包装箱：状态无效，继续采样。
- 目标超过货架 ROI、过期或世界坐标非法：丢弃该观测。
- 空层证据为 UNKNOWN 或与语义补集冲突：不放置。
- 接触/释放/回撤超过有限预算：进入阻塞或安全停止。

## 调试素材

建议记录每层的彩色物层号、包装箱层号、空层票数、置信度、中心坐标、当前放置子阶段和裁判结果。空层测试需覆盖 L1、L2、L3 三种布局，并单独保留 L1 主动观察截图。
